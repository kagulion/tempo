# Радио

Виджет, в котором играет интернет-радиостанции со всего мира. Станции и страны берутся из открытой базы [Radio Browser](https://www.radio-browser.info).

Загруженная музыка (`src/assets/music/`) временно скрыта флагом `musicEnabled` в [`src/App.tsx`](../src/App.tsx). Её плеер лежит в [`src/widgets/music/BackgroundMusic.tsx`](../src/widgets/music/BackgroundMusic.tsx).

На экране виджет расставляет `App.tsx`: он отвечает только за положение (правый нижний угол, над [панелью](widgets.md#панель)), всё остальное внутри `src/widgets/radio/`. Если закрыть окно радио на панели, радио продолжит играть. Поверх радио можно включить [фоновые звуки](ambience.md).

## Откуда берутся станции

```mermaid
flowchart LR
    A[fetchStations] --> B{Зеркало отвечает<br/>за 5 секунд?}
    B -- нет --> C[Следующее зеркало<br/>de1 → de2 → fi1]
    C --> B
    B -- да --> D[Топ-300 станций страны<br/>по голосам]
    D --> E{Играбельна?}
    E -- "http, HLS, .m3u8,<br/>редкий кодек" --> X[Отбрасываем]
    E -- да --> F{Дубль по названию?}
    F -- да --> X
    F -- нет --> G[Список станций]
    G --> H[shuffle]
```

- **Играбельна** означает, что поток идёт по `https` (на https-сайте браузер не даст играть http), это не HLS и кодек один из `MP3`, `AAC`, `AAC+`, `OGG`.
- **Страны** загружает `fetchCountries`. В список попадают только страны, где 10 и больше станций. Названия переводятся на русский через `Intl.DisplayNames`.
- **Страна по умолчанию** определяется по языку браузера (`ru-RU` → `RU`), запасной вариант `US`.

## Состояния загрузки

`status` из `useRadio` показывает, что сейчас в верхнем ряду виджета: комбобокс станций или текст.

```mermaid
stateDiagram-v2
    [*] --> loading: старт страницы
    loading --> idle: станции найдены
    loading --> empty: 0 станций
    loading --> error: API недоступен
    idle --> loading: смена страны / случайное радио /<br/>избранное из другой страны
    empty --> loading: смена страны
    error --> loading: смена страны
    idle --> error: ни одна станция<br/>в списке не запустилась
```

| Статус    | Что видно вместо комбобокса станций     |
| --------- | --------------------------------------- |
| `idle`    | Комбобокс станций                       |
| `loading` | «Ищем станции…», крутится иконка кубика |
| `empty`   | «В этой стране нет доступных станций»   |
| `error`   | «Не удалось подключиться к радио»       |

## Основные сценарии

### Смена страны, случайное радио, избранное

```mermaid
flowchart TD
    A[Выбрал страну] --> L
    B[Нажал кубик] --> L
    C[Выбрал избранное] --> Q{Станция из<br/>текущей страны?}
    Q -- да --> P[Включается сразу]
    Q -- нет --> L
    L[Загрузка станций страны] --> R[Играет первая станция]
```

Что происходит в каждом случае:

- **Страна из комбобокса** вызывает `loadStations(code)`.
- **Кубик** (`randomCountry`) берёт случайную страну, где 30 и больше станций, кроме текущей, и тоже вызывает `loadStations(code)`.
- **Избранное** (`playStation`) включает станцию сразу, если она есть в текущем списке. Иначе вызывает `loadStations(station.countrycode, station)`: выбранная станция встаёт первой, даже если выпала из топ-300.

`stationsRequest` хранит номер последнего запроса. Если пользователь быстро переключил страны, ответ на старый запрос приходит позже и просто игнорируется.

### Станция не запускается

```mermaid
flowchart TD
    A["audio onError"] --> B[failedStations + 1]
    B --> C{failedStations ≥<br/>число станций?}
    C -- нет --> D[nextStation]
    D --> E{Заиграла?}
    E -- "onPlaying" --> F[failedStations = 0]
    E -- "onError" --> A
    C -- да --> G["status = error"]
```

Когда станция закончила вещание (`onEnded`), тоже включается следующая.

## Кнопки виджета

Нижний ряд слева направо:

| Кнопка             | Иконка                                | Функция                          | Что делает                                                      | Неактивна                        |
| ------------------ | ------------------------------------- | -------------------------------- | --------------------------------------------------------------- | -------------------------------- |
| Случайное радио    | `Dices` (при загрузке `LoaderCircle`) | `randomCountry`                  | Случайная страна, первая станция перемешанного списка           | Во время загрузки                |
| Вкл/выкл           | `Pause` / `Play`                      | `togglePlaying`                  | Пауза или запуск. При включении поток перезагружается           | Никогда                          |
| Без звука          | `VolumeX` / `Volume1` / `Volume2`     | `toggleMuted`                    | Глушит звук, громкость при этом запоминается                    | Никогда                          |
| Громкость          | слайдер                               | `changeVolume`                   | 0–1, шаг 0.01. Сдвиг слайдера выше нуля снимает режим без звука | Никогда                          |
| Предыдущая станция | `SkipBack`                            | `prevStation`                    | Назад по перемешанному списку, по кругу                         | Загрузка или нет станций         |
| Следующая станция  | `SkipForward`                         | `nextStation`                    | Вперёд по перемешанному списку, по кругу                        | Загрузка или нет станций         |
| В избранное        | `Heart` (залито, если в избранном)    | `toggleFavorite`                 | Добавляет или убирает текущую станцию                           | Нет станции или статус не `idle` |
| Список избранного  | `ChevronDown`                         | `ComboboxButton` → `playStation` | Список избранного с поиском и страной у каждой станции          | Никогда                          |

Верхний ряд: подпись «Radio», комбобокс страны (`loadStations`) и комбобокс станции (`playStation`).

## Состояние и хранение

Всё, кроме избранного, живёт в `useRadio`.

### При загрузке страницы

Радио всегда выключено: звук включает только пользователь кнопкой «Вкл/выкл». Если в `localStorage` есть последняя станция, загружается её страна и она стоит первой в списке, но не играет. Если сохранённой станции нет, грузится страна по языку браузера и первой стоит случайная станция.

Пока радио выключено, у `<audio>` стоит `preload="none"`, поэтому поток не качается в фоне.

| Что                                   | Где                                                 | Переживает перезагрузку?                                |
| ------------------------------------- | --------------------------------------------------- | ------------------------------------------------------- |
| `playing`: играет или на паузе        | `useState`                                          | Нет, радио всегда стартует выключенным                  |
| `volume`, `muted`                     | `useState`                                          | Нет, громкость сбрасывается на 0.8                      |
| Приглушение вокруг сигнала таймера    | `useDuckLevel` (множитель к `volume`)               | Нет. Подробно в [timer.md](timer.md#приглушение-музыки) |
| `country`: код текущей страны         | `useState`                                          | Страна последней станции, иначе по языку браузера       |
| `stations`: перемешанный список       | `useState`                                          | Нет                                                     |
| `currentStation`: индекс в `stations` | `useState`                                          | Нет, но последняя станция восстанавливается             |
| Последняя заигравшая станция          | `localStorage`                                      | **Да**                                                  |
| `countries`                           | `useState`                                          | Нет                                                     |
| `favorites`                           | `useState` + `localStorage` в `useFavoriteStations` | **Да**                                                  |
| `stationsRequest`                     | `useRef`                                            | Нет. Номер последнего запроса станций                   |
| `failedStations`                      | `useRef`                                            | Нет. Сколько станций подряд не запустилось              |

### Что лежит в localStorage

| Ключ                      | Что                                                            | Когда пишется                                                     |
| ------------------------- | -------------------------------------------------------------- | ----------------------------------------------------------------- |
| `tempo:last-station`      | Последняя станция целиком, в том же формате, что и в избранном | Когда станция реально заиграла (`onPlaying`), а не просто выбрана |
| `tempo:favorite-stations` | Избранное                                                      | При нажатии на сердечко                                           |

### Формат избранного

Ключ `localStorage`: `tempo:favorite-stations`. Значение — объект «uuid станции → станция целиком»:

```json
{
	"<uuid станции>": {
		"stationuuid": "<uuid станции>",
		"name": "Русский микс",
		"country": "The Russian Federation",
		"countrycode": "RU",
		"url_resolved": "https://…",
		"codec": "AAC+",
		"hls": 0
	}
}
```

Станция хранится целиком, чтобы её можно было показать и включить без запроса к API. Если `localStorage` недоступен (приватный режим), избранное живёт до перезагрузки страницы.

## Неочевидные решения

- **Станции перемешаны, но в комбобоксе отсортированы.** Список `stations` перемешан, чтобы «следующая», «предыдущая» и «случайное радио» каждый раз давали разное, а не одни и те же лидеры рейтинга. Комбобокс показывает копию списка по алфавиту (`stationOptions`), чтобы в нём было удобно искать.
- **После паузы поток перезагружается.** Прямой эфир после паузы продолжился бы с того места, где его остановили. Поэтому `togglePlaying` при включении вызывает `audio.load()`, и звук возвращается к живому эфиру.
- **Последняя станция сохраняется по `onPlaying`.** Если сохранять при выборе, после перезагрузки можно получить станцию, которая так и не запустилась. Поэтому в `tempo:last-station` попадает только станция, из которой реально пошёл звук.
- **Запуск после первого клика остался в `useAutoplay`.** Радио теперь включается кнопкой, а это и есть клик, поэтому браузер звук не блокирует. Запасной путь нужен фоновой музыке, которая стартует сама.
- **Избранная станция могла выпасть из топа.** `fetchStations` берёт только 300 популярных станций страны. Если избранной там нет, `loadStations(code, first)` всё равно ставит её первой в список из сохранённых данных.
- **Выбор избранного может сменить страну.** Если выбранная станция из другой страны, загружается её страна, иначе «следующая» и «предыдущая» не имели бы смысла.
- **Повторы в базе отсеиваются.** В Radio Browser одна станция часто записана несколько раз с разными адресами. Остаётся первая, то есть самая популярная, по ключу «название + страна».
