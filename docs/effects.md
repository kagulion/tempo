# Эффекты

Анимированные частицы поверх всей страницы: огоньки, дождь, снег. Эффекты можно включать вместе, например огоньки с дождём, или выключить все. Каждая карточка в окне работает как переключатель, подсвеченная — эффект включён.

Окно открывается кнопкой «Эффекты» (искры) в группе «Вид» в правом нижнем углу ([панель](widgets.md#панель)). Оно стоит на месте галереи обоев: открытие эффектов закрывает обои и наоборот (`sharedSlots` в [`useDock.ts`](../src/widgets/dock/useDock.ts)). Положение задаёт [`src/App.tsx`](../src/App.tsx): правый столбец под таймером, на телефоне — над панелью во всю ширину.

## Список эффектов

| id       | Название | Что делает                                                                        | Частиц на 1920×1080 |
| -------- | -------- | --------------------------------------------------------------------------------- | ------------------- |
| `embers` | Огоньки  | Искры поднимаются снизу, покачиваются, мерцают и гаснут. Светятся (`lighter`)     | 75                  |
| `rain`   | Дождь    | Тонкие штрихи падают с лёгким наклоном. Дальние капли короче, медленнее и бледнее | 320                 |
| `snow`   | Снег     | Хлопья медленно падают и покачиваются. Ближние крупнее, быстрее и ярче            | 170                 |

При первом заходе включены только огоньки — так было до окна эффектов.

## Как это работает

- **Один эффект — один `<canvas>`.** `App.tsx` рисует `EffectCanvas` для каждого включённого эффекта. Выключенный эффект удаляется со страницы вместе с холстом и циклом отрисовки, поэтому ничего не тратит.
- **Холсты поверх всего** (`fixed inset-0 z-50`), включая окна и панель, но с `pointer-events-none`: клики проходят насквозь.
- **`EffectCanvas` — общая часть.** Он подгоняет размер холста под окно с учётом `devicePixelRatio` (не больше 2), крутит `requestAnimationFrame` и останавливает его, пока вкладка скрыта. Шаг времени `dt` ограничен 0.1 с, чтобы после паузы частицы не прыгали.
- **Рендерер — сам эффект.** Это объект с двумя функциями (тип `EffectRenderer` в `renderers/types.ts`):
  - `init(width, height)` — один раз заполняет весь экран частицами, чтобы эффект не «натекал» с края после включения;
  - `draw(ctx, dt, now, width, height)` — сдвигает частицы на `dt` секунд и рисует их. Холст перед вызовом уже очищен, режим наложения сброшен на обычный.
- **Частица, ушедшая за край, рождается заново** у противоположного края. Так число частиц постоянно.
- **Плотность.** Дождь и снег пересчитывают число частиц под размер экрана через `scaledCount`: на маленьком экране частиц меньше, но не меньше трети. Огоньки — всегда 75, как было.
- **Сохранение.** Список включённых id хранится в `localStorage` под ключом `tempo:effects`, например `["embers","rain"]`. Неизвестные id при загрузке отбрасываются.

## Как добавить эффект

1. Создай `src/widgets/effects/renderers/<имя>.ts` с функцией, которая возвращает `EffectRenderer`. Частицы держи в массиве внутри функции:

   ```ts
   import { scaledCount, type EffectRenderer } from './types';

   export function createFireflies(): EffectRenderer {
   	const particles: { x: number; y: number }[] = [];

   	return {
   		init(width, height) {
   			particles.length = 0;
   			for (let i = 0; i < scaledCount(60, width, height); i++) {
   				particles.push({ x: Math.random() * width, y: Math.random() * height });
   			}
   		},
   		draw(ctx, dt, now, width, height) {
   			// сдвинуть частицы на dt секунд, вернуть ушедшие за край и нарисовать
   		}
   	};
   }
   ```

   Скорости задавай в пикселях в секунду и умножай на `dt` — тогда эффект одинаков при любой частоте кадров.

2. Добавь id в тип `EffectId` и запись в массив `effects` в `effects.ts`: название, иконку из `lucide-react` и `create`. Место в массиве — место карточки в окне.
3. Если карточек станет больше трёх, проверь сетку в `EffectsWidget.tsx` (`grid-cols-3`).
4. Включи эффект и проверь на большом и маленьком экране: частиц не слишком много, анимация плавная, окна читаются.
5. Добавь строку в [список эффектов](#список-эффектов).

## Как изменить эффект

- **Плотность** — константа `count` в файле эффекта.
- **Скорость, размер, яркость** — в функции, которая создаёт частицу (`createDrop`, `createFlake`, `createEmber`). У дождя и снега всё зависит от `depth` (0 — далеко, 1 — близко): поменяй границы, и ближние и дальние частицы изменятся согласованно.
- **Наклон дождя** — `slant` в `rain.ts`.
- **Эффекты по умолчанию** — `defaultActive` в `useActiveEffects.ts`.
