# Эффекты

Анимированные частицы поверх страницы: огоньки, дождь, ливень, снег, листья, сакура, светлячки и тени облаков. Эффекты можно включать вместе, например огоньки с дождём, или выключить все. Каждая карточка в окне работает как переключатель, подсвеченная — эффект включён.

Справа от заголовка окна, как у [звуков](ambience.md), две кнопки:

- **Сброс** (↺) — выключает все эффекты.
- **Пауза** (⏸ / ▶) — замораживает включённые эффекты на месте: частицы остаются на экране, но не двигаются, и процессор не тратится. Пауза запоминается и после перезагрузки. Включение любого эффекта снимает паузу — так же, как включение звука запускает звуки.

Обе кнопки неактивны, если ни один эффект не включён. Кнопка паузы тогда показывает ▶ — как у звуков: ⏸ видна, только когда эффекты действительно идут.

Окно открывается кнопкой «Эффекты» (искры) в группе «Вид» в правом нижнем углу ([панель](widgets.md#панель)). Оно стоит на месте галереи обоев: открытие эффектов закрывает обои и наоборот (одинаковый `slot` в реестре [`src/widgets/registry.ts`](../src/widgets/registry.ts)). Положение задаёт тот же реестр: правый столбец под таймером, на телефоне — над панелью во всю ширину.

## Как это работает

- **Один эффект — один `<canvas>`.** [`EffectLayers.tsx`](../src/widgets/effects/EffectLayers.tsx) рисует `EffectCanvas` для каждого включённого эффекта. Окно и холсты читают одно общее состояние из `useActiveEffects` (хранилище `createPersistentStore`), поэтому `App.tsx` ничего им не передаёт. Выключенный эффект удаляется со страницы вместе с холстом и циклом отрисовки, поэтому ничего не тратит.
- **Два слоя** — поле `layer` у эффекта. `front` — поверх всего, включая окна и панель (`z-50`). `back` — над обоями, но под окнами (`z-[1]`): так стоят тени облаков, иначе они затемняли бы окна. Холсты с `pointer-events-none`: клики проходят насквозь.
- **`EffectCanvas` — общая часть.** Он подгоняет размер холста под окно с учётом `devicePixelRatio` (не больше 2), крутит `requestAnimationFrame` и останавливает его, пока вкладка скрыта. Шаг времени `dt` ограничен 0.1 с, чтобы после паузы частицы не прыгали.
- **Пауза** — проп `paused` у `EffectCanvas`. Цикл дорисовывает текущий кадр и больше не запрашивает следующий; холст с частицами остаётся. Частицы при этом не пересоздаются: после снятия паузы эффект продолжается с того же места. Первый кадр рисуется всегда, поэтому после перезагрузки на паузе эффект виден. При изменении размера окна кадр перерисовывается без движения (`dt = 0`).
- **Рендерер — сам эффект.** Это объект с двумя функциями (тип `EffectRenderer` в `renderers/types.ts`):
  - `init(width, height)` — один раз заполняет весь экран частицами, чтобы эффект не «натекал» с края после включения;
  - `draw(ctx, dt, now, width, height)` — сдвигает частицы на `dt` секунд и рисует их. Холст перед вызовом уже очищен, режим наложения сброшен на обычный.
- **Частица, ушедшая за край, рождается заново** (светлячки — появляются с противоположной стороны). Так число частиц постоянно.
- **Плотность.** Большинство эффектов пересчитывают число частиц под размер экрана через `scaledCount`: на маленьком экране частиц меньше, но не меньше трети. Огоньки — всегда 75, как было; тени облаков — всегда 5, но их размер и скорость растут с экраном.
- **Молния ливня** отключена, если в системе включено «уменьшить движение»: резкая смена яркости бывает неприятна.
- **Сохранение.** Включённые эффекты и пауза хранятся в `localStorage` под ключом `tempo:effects`, например `{"active":["embers","rain"],"paused":false}`. Неизвестные id при загрузке отбрасываются. Старый формат — просто массив id — тоже читается.

## Как добавить эффект

1. Создай `src/widgets/effects/renderers/<имя>.ts` с функцией, которая возвращает `EffectRenderer`. Частицы держи в массиве внутри функции:

   ```ts
   import { scaledCount, type EffectRenderer } from './types';

   export function createBubbles(): EffectRenderer {
   	const particles: { x: number; y: number }[] = [];

   	return {
   		init(width, height) {
   			particles.length = 0;
   			for (let i = 0; i < scaledCount(60, width, height); i++) {
   				particles.push({ x: Math.random() * width, y: Math.random() * height });
   			}
   		},
   		draw(ctx, dt, now, width, height) {
   			// сдвинуть частицы на dt секунд, вернуть ушедшие за край и нарисовать
   		}
   	};
   }
   ```

   Скорости задавай в пикселях в секунду и умножай на `dt` — тогда эффект одинаков при любой частоте кадров.

2. Добавь id в тип `EffectId` и запись в массив `effects` в `effects.ts`: название, иконку из `lucide-react`, `create` и `layer` (`front` почти всегда, `back` — если эффект затемняет или иначе мешает читать окна). Место в массиве — место карточки в окне.
3. Сетка в `EffectsWidget.tsx` — 4 колонки, на телефоне 2. Если число карточек не делится на 4, последний ряд будет неполным.
4. Включи эффект и проверь на большом и маленьком экране: частиц не слишком много, анимация плавная, окна читаются.
5. Добавь строку в [список эффектов](#список-эффектов).

## Как изменить эффект

- **Плотность** — константа `count` в файле эффекта.
- **Скорость, размер, яркость** — в функции, которая создаёт частицу (`createDrop`, `createFlake`, `createEmber` и т. д.). У дождя и ливня это настройки в `createRain` и `createHeavyRain`, у листьев и сакуры — в `createLeaves` и `createCherryBlossom`. У большинства эффектов всё зависит от `depth` (0 — далеко, 1 — близко): поменяй границы, и ближние и дальние частицы изменятся согласованно.
- **Наклон дождя** — `slant` в `createRain` / `createHeavyRain`.
- **Частота молнии** — `nextFlash` в `rain.ts`, её форма — `flashAlpha`.
- **Темнота теней облаков** — `darkness` в `cloudShadows.ts`.
- **Эффекты по умолчанию** — `defaultActive` в `useActiveEffects.ts`.
