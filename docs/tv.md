# ТВ-фон

Телеканал на весь экран вместо обоев: небольшой отобранный список каналов из каталога [iptv-org](https://github.com/iptv-org/iptv) (музыка, релакс, природа, путешествия). Окно «ТВ» открывается кнопкой в группе «Вид» ([панель](widgets.md#панель)) и стоит на том же месте, что обои, YouTube, эффекты и затемнение: они заменяют друг друга. Каналы разбиты по категориям, плитка — логотип и название. Клик по плитке сразу ставит фон, выбранный канал подсвечен. Пока фон — канал, в шапке окна кнопки паузы и звука.

## Как это работает

- **Выбор.** Фон хранится как `id` обоев: `tv/<id канала>` в `tempo:wallpaper`. Если канала нет в `tvChannels` (его убрали), при загрузке открываются обои по умолчанию.
- **Воспроизведение.** `TvLayer` проверяет `video.canPlayType('application/vnd.apple.mpegurl')`: Safari играет HLS сам. Иначе библиотека `hls.js` подгружается динамическим `import()` отдельным чанком, только когда выбран канал. Видео — `object-cover`, без звука по умолчанию.
- **Звук.** Как у YouTube: включается кнопкой, только после действия пользователя и только у главного слоя; громкость умножается на `duckLevel` ([`src/lib/ducking.ts`](../src/lib/ducking.ts)), поэтому глохнет около сигнала таймера.
- **Пауза** — по кнопке, в скрытой вкладке (только если канал без звука: со звуком он играет дальше) и при `prefers-reduced-motion`.
- **Ошибки.** Фатальная ошибка hls.js, `error` у `<video>` или молчание дольше 15 секунд (`tvStartTimeoutMs`) — окно ТВ показывает сообщение, а фон остаётся прежним, не чёрным. Если канал оборвался, когда он уже был фоном, открываются обои по умолчанию.
- Закрытое окно остаётся смонтированным, а фон продолжает играть: так и задумано.

## Как добавить канал

1. Найди канал в каталоге iptv-org, у которого есть `https`-поток `.m3u8`.
2. **Проверь поток.** Сайт играет его прямо в браузере, поэтому нужны `https` и заголовок `Access-Control-Allow-Origin` (иначе CORS не даст hls.js прочитать плейлист):

   ```bash
   curl -sI -H "Origin: https://example.com" "https://…/playlist.m3u8" | grep -i "access-control\|HTTP"
   curl -s "https://…/playlist.m3u8" | head -3   # должно начинаться с #EXTM3U
   ```

3. Добавь запись в массив `tvChannels` в `channels.ts`:

   ```ts
   { id: 'Example.us', title: 'Example TV', category: 'relax', url: 'https://…/playlist.m3u8', logo: 'https://…/logo.png', country: 'US' }
   ```

   `id` — id канала из iptv-org (по нему выбор хранится в `localStorage`, менять его нельзя), `logo` и `country` необязательны. Порядок плиток — порядок записей.

4. Открой окно ТВ и проверь: плитка на месте, клик ставит фон, поток играет.

## Как добавить категорию

Добавь значение в тип `TvCategory` и запись `{ value, label }` в `tvCategories` в `channels.ts`. Порядок секций в окне — порядок массива.

## Как убрать канал

Удали запись из `channels.ts`. У тех, кто выбрал этот канал, откроются обои по умолчанию.

## Ограничения

Бесплатные потоки живут недолго: каналы пропадают и меняют адреса. Если канал стал недоступен, окно покажет «Канал недоступен» — убери его или поменяй `url`.
